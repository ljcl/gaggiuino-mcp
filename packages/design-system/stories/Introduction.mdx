# Gaggiuino MCP design system

Shared tokens, host-theme presets, and presentational components used by the
Shot Graph MCP App.

- **Design System**: color, typography, spacing tokens, and the host-theme
  presets that mirror what `useHostStyles` applies in production.
- **UI**: presentational React components (Legend, Skeleton, Tooltip).
- **Shot Graph**: the MCP App itself.

Use the **Host Theme** toolbar to preview a story as Claude or ChatGPT renders
it, and the viewport toolbar (`Claude iOS Card`) to check mobile layout.
